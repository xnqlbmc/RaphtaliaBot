## 💻 - Instalação via Windows
**Essenciais**
```
winget install nodejs ffmpeg Git.Git yt-dlp
```
**Criar a pasta do bot:**
```
git clone https://github.com/xnqlbmc/RaphtaliaBot
```
**Iniciar o bot:**
```
cd RaphtaliaBot && npm start
```

## 💾 START DO BOT 💾 
```
npm start
```
---

## 📱- Instalação Via Termux/Linux
**Essenciais**
```
apt-get update -y && pkg upgrade -y && pkg update -y && pkg install nodejs -y && pkg install ffmpeg -y && pkg install git -y && pkg install yt-dlp -y
```
**ATENÇÃO:**
Será necessário digitar "y" toda vez que pedir a caixa [y/n]

**Permissão do Termux para ler os arquivos:**
```
termux-setup-storage
```
**Criar a pasta do bot:**
```
cd /sdcard/Download && git clone https://github.com/xnqlbmc/RaphtaliaBot
```
**Iniciar o bot:**
```
cd /sdcard/Download/RaphtaliaBot && npm start
```

## 💾 START DO BOT 💾 
```
npm start
```
